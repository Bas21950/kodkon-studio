กดก่อนคิดทีหลัง Studio — โปรแกรมทำงานในเครื่อง Windows

เปิดโปรแกรมจาก shortcut ที่ Desktop หรือ Start Menu
โปรแกรมจะแสดงเป็นหน้าต่างแอปโดยตรง ไม่เปิดแท็บเบราว์เซอร์หรือหน้าต่าง CMD
ถ้าใช้แบบ portable ให้ดับเบิลคลิก Start Studio.vbs

โครงสร้าง
- App\KodKon Studio : โปรแกรมและไฟล์อัปเดต
- Data : ฐานข้อมูล งาน วิดีโอ/เสียง และการตั้งค่าเฉพาะเครื่อง
- Backups : วางไฟล์สำรองไว้ที่นี่ได้

ครั้งแรกต้องมี Python 3.11 ขึ้นไป, FFmpeg/FFprobe, Microsoft Edge WebView2 Runtime และอินเทอร์เน็ตสำหรับติดตั้งแพ็กเกจ
โปรแกรมจะเก็บข้อมูลไว้ใน Data ที่อยู่ข้างนอกโฟลเดอร์ App และไม่รวมข้อมูลส่วนตัวใน GitHub Release
ตัวติดตั้งและตัวถอนการติดตั้งจะไม่ลบ Data หรือ Backups
