# สำรองและกู้คืนข้อมูล

## สำรองข้อมูล

เปิดเมนู **ตั้งค่าโปรแกรม → สำรองและกู้คืนข้อมูล → ดาวน์โหลดไฟล์สำรอง** ไฟล์ ZIP มี snapshot ฐานข้อมูลและไฟล์ในคลังสื่อของโปรเจกต์ ข้อมูลชั่วคราวจากงานที่ถูกขัดจังหวะจะไม่รวมอยู่ในไฟล์

ไฟล์สำรองไม่มี Gemini API key หรือ Facebook Page token เพราะคีย์เหล่านั้นปกป้องด้วย Windows DPAPI แยกจากฐานข้อมูล เก็บไฟล์ ZIP ไว้ในตำแหน่งที่ปลอดภัยและมีพื้นที่ว่างพอ

## กู้คืนข้อมูล

1. ปิด Studio ก่อนกู้คืน
2. เปิด PowerShell ที่โฟลเดอร์โปรแกรม
3. รันคำสั่ง โดยแทนที่ path ด้วยตำแหน่งไฟล์ ZIP:

   ```powershell
   .\scripts\restore.ps1 -BackupPath "C:\path\kodkon-studio-backup.zip"
   ```

4. ตรวจวันเวลาของไฟล์สำรองและพิมพ์ `RESTORE` เพื่อยืนยัน
5. เปิด Studio ใหม่ด้วย `scripts/start.ps1`

ตัวกู้คืนตรวจ manifest, path ภายใน ZIP, symbolic link และ `PRAGMA integrity_check` ก่อนแตะข้อมูลเดิม จากนั้นเก็บสำเนาฐานข้อมูล/สื่อปัจจุบันไว้ใน `%LOCALAPPDATA%\KodKonStudio\backups\pre-restore-*.zip` แล้วแทนเฉพาะฐานข้อมูลและสื่อ โฟลเดอร์ DPAPI secrets และการตั้งค่าในเครื่องไม่ถูกนำเข้าจาก ZIP

เมื่อย้ายไปเครื่องหรือบัญชี Windows อื่น ให้ใส่ Gemini API key และ Page token ใหม่ในหน้าตั้งค่า คีย์ที่ถูกปกป้องด้วย DPAPI จะถอดรหัสข้ามบัญชี Windows ไม่ได้

## ไฟล์ชั่วคราว

เมื่อเปิดแอป โปรแกรมลบเฉพาะไฟล์อัปโหลด `.upload`, โฟลเดอร์อ่านเฟรม OCR และโฟลเดอร์ render ชั่วคราวที่อายุเกิน 24 ชั่วโมง การล้างนี้ไม่ลบไฟล์ที่ผูกกับโปรเจกต์หรือผลเรนเดอร์ที่สำเร็จ
